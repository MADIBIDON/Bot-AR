# Hosting the UCP agent profile (one-time setup)

Shopify's Universal Commerce Protocol (UCP) requires every calling agent
to publish its own profile document at a stable, redirect-free HTTPS URL
before a merchant's UCP endpoint will answer any tool call. Without this,
every call fails immediately with `profile_unreachable` — confirmed live
against both Kairyu and RelicTCG during Phase 20/21 recon.

The profile itself (`docs/agent-profile.json`) is generated by
`python -m ucp.profile` and contains no secret — it only declares the
UCP protocol version and empty service/payment-handler registries (this
agent never exposes its own UCP services and never handles payment
itself).

## Setup (GitHub Pages, chosen for simplicity — no CLI, no account beyond GitHub)

1. Create a **public** GitHub repository (GitHub Pages' free tier
   requires a public repo unless you have GitHub Pro/Team/Enterprise).
2. Add it as this project's remote and push:
   ```bash
   git remote add origin <your-repo-url>
   git push -u origin main
   ```
3. In the repo's **Settings → Pages**, set:
   - Source: **Deploy from a branch**
   - Branch: **main**, folder: **/docs**
4. GitHub publishes the site within a minute or two, at:
   ```
   https://<your-github-username>.github.io/<repo-name>/agent-profile.json
   ```
5. Tell the assistant that URL — it's needed to configure the Shopify
   UCP purchase connector (`PURCHASE_UCP_AGENT_PROFILE_URL` in `.env`,
   not a secret, just needs to be the exact public URL).

## Updating the profile later

```bash
python -m ucp.profile
git add docs/agent-profile.json
git commit -m "Update UCP agent profile"
git push
```

GitHub Pages picks up the change automatically — no rebuild step, no
CI/CD needed for a static JSON file.

## Verifying it's live

```bash
curl -s https://<your-github-username>.github.io/<repo-name>/agent-profile.json
```

Should return the same JSON as `docs/agent-profile.json`, with
`Content-Type: application/json` (GitHub Pages sets this automatically
for `.json` files).
